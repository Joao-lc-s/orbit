O que é JSON? É só seguir este formato (copie e cole para testar):

[
  {
    "topic": "História",
    "text": "Quem descobriu o Brasil?",
    "options": ["Colombo", "Cabral", "Caminha", "Vespucci"],
    "correctIndex": 1
  }
]

Dica: O "correctIndex" começa do 1. 1 = Letra A, 2 = Letra B, etc.
